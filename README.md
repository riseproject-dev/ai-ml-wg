# RISE AI/ML WG

## About RISE

[RISE](https://riseproject.dev) is a collaborative, industry-led initiative under the Linux Foundation that accelerates open-source software development for the RISC-V architecture.

## Charter

This working group is a place for RISE members to collaborate on AI/ML initiatives within the RISC-V ecosystem. Our objectives are to:

- Help collaboration across companies to avoid duplication of work
- Accelerate AI/ML frameworks and libraries on RISC-V
- Communicate on the readiness of the respective ecosystems

## Project Tracking

Work is tracked on our [project board](https://github.com/orgs/riseproject-dev/projects/17).
